Release notes

What changed in each version of Undertone. The newest is at the top.

Version 1.2 21 November 2026Latest

  • Widget buttons fixed: every button now works, and with nothing loaded, play brings back your last queue.
  • One smart, resizable widget replaces the three older ones. Larger sizes show the cover behind the title, and add shuffle, repeat and Add.
  • A new one-tap playlist button widget. Place as many as you like.
  • Shuffle Library starts playing without opening the app.

Version 1.1 15 November 2026

  • Settings › Lock screen and widgets: show the player on the lock screen, and shuffle and repeat buttons there and in the notification.
  • A faster switch to the backup engine when a link is refused or a song has gone.
  • The phone stays awake and on Wi-Fi while casting with the screen off.
  • A search result that appeared twice can no longer crash the results list.

Version 1.0 14 November 2026

  • First release.

Checking your download

The file for version 1.2 is called Undertone.apk. It is 63.6 MB (63,552,690 bytes). Its SHA-256 checksum is:

7992430831cde0aa828ec8b8862ccae4611857a4ef21a315c8b42a5c194a2e18

On Windows, run certutil -hashfile Undertone.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
